## 怎么使用

1. 从[最新版](https://github.com/tosamakamila/ppt-takeaway/releases/latest)下载压缩包并解压。
2. 第一次使用先双击 `setup.bat`，等待窗口提示准备完成。此步骤需要联网；以后不用重复运行。
3. 在微信里打开“智慧课堂”，进入想整理的课程回放，再双击 `run_ppt_extractor.bat`。
4. 锁定智慧课堂窗口并框选 PPT 区域，然后选择“自动”或“手动”：自动模式设置要整理的周次后开始；手动模式播放到需要的页面时点“保存当前页”。
5. 需要的话，先选择图片保存位置。完成后，按课程名称整理的图片和 PDF 就会保存在那里。

自动模式会按课程时间顺序处理；第一周从第二次课开始。检测过程中请不要最小化微信窗口。

本工具用于 Windows。首次准备会自动下载所需文件，请保持窗口打开；程序和依赖都放在项目文件夹内，不会修改系统 PATH。

## 配套项目：教材整理 AI Skill

[final-examination-helper — 教材整理 AI Skill](https://github.com/tosamakamila/final-examination-helper)提供从课程资料到凝练复习教材的制作流程。

本工具收集的课件图片和 PDF 可以作为该 Skill 的输入，再配合课本逐章整理知识、展开机制、比较概念并核对覆盖范围。目前重点支持生物学教材，试卷和辅导书可作为补充资料。

使用顺序：**收集课件 → 配合课本制作复习教材 → 核对原始资料并学习**。教材制作由支持 Skill 的 AI 助手完成；课件收集助手可单独使用。
